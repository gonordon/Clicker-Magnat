Clicker Magnat

1. Назва та короткий опис проєкту:
  Clicker Magnat — браузерна гра-клікер, у якій гравець натискає на кнопку, заробляє монети та купує покращення.

2. Проблема, мета та цільова аудиторія:
  Проблема, яку вирішує вебзастосунок:  Користувачам потрібна проста гра для відпочинку, яка не потребує встановлення на пристрій. Clicker Magnat дозволяє грати безпосередньо в браузері.  Мета проєкту:
створити просту браузерну гру з накопиченням монет і системою покращень.  Цільова аудиторія: учні, студенти та любителі простих ігор.

3. Ролі користувачів:
  Гість: перегляд головної сторінки, правил і рейтингу, реєстрація.
  Користувач: гра, купівля покращень, перегляд статистики та керування профілем.
  Модератор: перегляд скарг і контроль дотримання правил.
  Адміністратор: керування користувачами, ролями та налаштуваннями гри.

4. Основні функції та сторінки:
  Основні функції:
      Реєстрація та вхід.
      Накопичення монет натисканням на кнопку.
      Магазин покращень.
      Збереження ігрового прогресу.
      Перегляд статистики та рейтингу.
      Керування профілем.
      Модерація скарг.
      Адміністрування користувачів.
  Перелік сторінок вебзастосунку:
      Сторінка / Призначення
      Головна / Ознайомлення з грою
      Ігрова сторінка / Основний ігровий процес
      Магазин / Купівля покращень
      Реєстрація та вхід / Авторизація
      Особистий кабінет / Керування профілем
      Таблиця лідерів / Перегляд рейтингу
      Панель модератора / Опрацювання скарг
      Панель адміністратора / Керування системою
